# Timewarp downloads

Official signed desktop installers and checksums for [Timewarp](https://timewarpdev.com).

Download the latest Mac installer from [Releases](https://github.com/vinceackermann2-sys/timewarp-releases/releases/latest).
Mac releases target Apple Silicon (arm64) and require macOS 12 or later.

Published DMGs are signed with Developer ID Application: Vincent Ackermann
(team `6XD78664VT`), accepted by Apple's notarization service, stapled, and checked
with Gatekeeper. Each release includes its SHA256 checksum and acceptance evidence.

The Windows app is distributed through the existing
[Microsoft Store listing](https://apps.microsoft.com/detail/9N6WRN6GN0KR).

This repository hosts release artifacts so downloads remain public independently
of the application source repository. Mac automatic updates are currently disabled;
install the current DMG to update manually.
